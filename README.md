Initial shared planck single_phase repository
Files:
1. switch_planck_ph0_on.f: f77 Monte Carlo calculation of newtonian virtual work from complete oscillation of source mass. Detector has cylindrical gravity mass with 8x the density of the substrate, and a symmetric cylindrical counterweight. Source has cylindrical gravity mass. Source substrate is centered on detector mass, so that substrate will not excite torsional mode.  Set a flag variable, "pflag" to 1 to turn on the cylindrical masses.  Setting pflag to 0 will turn off the masses, useful for calculation of Newtonian background of substrate.  Gap, amplitude, and detector length and width are read from external file; code will loop over varous values of these parameters, stored in each line of external file. Previous history of this code is summarized in the header.  "ph0" version runs for source phase of 0 (horizontal, initial position); new phase variable jj=0. Generates output files with _ph0 appended to name. "On" version has the correct placement of the Planck-mass-sized disks
3. big_G_input_planck.nb : Mathematica notebook to generate the input file for switch_planck_ph0_on.f; has the correctly sized mass disks.
4. big_G_input_planck.txt: sample ascii input file generated by big_G_input_planck.nb; this version needs to be opened by the program for it to function correctly. 
9. switch_planck_ph0_on.sbatch: script to run switch_planck_ph0_on in batch mode on UIUC campus cluster; change usernames and directories as appropriate.
